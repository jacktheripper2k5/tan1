# Oxygen Enrichment Calculator

Dark/yellow Streamlit interface for calculating pure oxygen required
to enrich 1000 Nm³ of dry air to a selected oxygen concentration.

## Files

- app.py
- requirements.txt
- README.md

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

For Streamlit deployment, upload these files to GitHub and select
`app.py` as the application entry point.
