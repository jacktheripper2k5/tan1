# Oxygen Enrichment Calculator

A Streamlit calculator for determining the volume and mass of pure oxygen
needed to enrich 1000 Nm³ of dry air to a selected oxygen concentration.

## Files

- `app.py`
- `requirements.txt`
- `README.md`

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

For Streamlit deployment, upload these files to a GitHub repository and
select `app.py` as the application entry point.
